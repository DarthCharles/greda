Extend the named spacing scale to sizing, positioning, and other spacing-based Tailwind utilities in the precompiled stylesheet. Classes such as `size-md`, `h-xl`, and `-translate-y-xs` use the same named tokens as the Tailwind 4 integration. Greda's `cn` helper merges these classes with numeric and arbitrary overrides.
