Add nine named spacing tokens from `--space-3xs` to `--space-3xl`. Use them in plain CSS or with padding, margin, and gap utilities such as `p-md`, `-mt-xs`, and `gap-sm`. The utilities ship in the precompiled stylesheet and are available through the Tailwind 4 token import. Existing components continue to use the numeric spacing scale.
