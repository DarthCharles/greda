# La Viuda catalog imagery

The product photographs below were generated with the built-in imagegen tool for the fictional ranch-shop composition. They are catalog assets, excluded from the published package. JPEG derivatives are resized to 1000 px for the example; the original generated PNGs remain in Codex's image output directory.
