# Cobalto

Cobalto is graphic, precise, and editorial. Cobalt blue works as both ink and
action color against paper-like backgrounds. Arial/Helvetica, heavy display
type, fine borders, and square corners give it a compact, deliberate rhythm.
Mixed heading weights and generous whitespace can create hierarchy without
adding more colors. Soft blue secondary controls sit apart from stronger blue
interaction fills and neutral supporting panels. Dark mode shifts to navy
surfaces with lighter blue actions and a brighter blue interaction fill.

Choose **cobalto** and **light / dark** in the toolbar to preview the theme.

## Install the theme and fonts

Components work with Greda's compiled package CSS, without Tailwind:

```tsx
import "@darthcharles/greda/styles.css";
import "@darthcharles/greda/themes/cobalto.css";
```

Set the theme and scheme on the same boundary:

```html
<html data-theme="cobalto" data-color-scheme="light">
```

Importing the theme alone leaves the neutral base unchanged. Switch the scheme
to explore the complementary palette. Your application controls its page shell:

```tsx
<body className="m-0 surface-primary font-sans text-primary">
  {/* Your application */}
</body>
```

The theme uses installed system fonts and downloads nothing. Override
`--font-sans` and `--font-heading` to use your own families.

## Compose the page

The recipe uses Tailwind layout utilities. With Tailwind 4 configured, use these
imports in your application CSS entry point instead of the JavaScript CSS imports:

```css
@import "tailwindcss";
@import "@darthcharles/greda/styles.css" layer(components);
@import "@darthcharles/greda/tokens.css";
@import "@darthcharles/greda/themes/cobalto.css";
```

Import that entry point once. Your application Tailwind build must scan the copied
JSX; recipe-only layout classes are not included in Greda's compiled CSS. The
components layer lets application utilities override component defaults.
Tailwind 3 consumers need corresponding token mappings in their configuration.

An 800-weight headline pairs with a 500-weight continuation, a decorative
asterisk, a rotated photo frame, and a primary link composed with Button. Import
Button, Label, and Textarea from `@darthcharles/greda`. A small field-notes area
provides a place to jot down a thought without adding another action. The serif italic caption, frame rotation, and
column width are local editorial choices. `font-medium` preserves the headline’s
mixed weights.

## Responsive layout and interaction

The composition narrows below 420px and the details strip wraps. The asterisk
is hidden from assistive technology; the photograph has descriptive alt text.

Tab focuses “Explore the notebook”; Enter moves focus to the details strip
with a visible outline. Button retains anchor semantics through `asChild`; its
loading and disabled props do not guarantee a disabled link. All editorial
content is fictional. There is no form, submission, animation, or saved state.
The field-notes textarea is keyboard accessible and keeps edits only while the
example is mounted. See individual component stories for disabled, loading, and
validation states.

## Scoped themes

Put `data-theme="cobalto"` and `data-color-scheme="light"` or `"dark"` on the
same wrapper. Apply surface, text, and font styles through the shared roles.
For portaled DialogContent, SelectContent, and TooltipContent, pass an element
inside that wrapper as `container` so the portal inherits the theme. A document
theme naturally reaches portals mounted under body.

Keep the theme's low-specificity selectors. Override base colors, typography,
and shape tokens after importing the theme to customize the result. The theme
provides variables; the consuming application controls page composition.
