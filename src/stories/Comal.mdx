# Comal

Comal takes its warmth from Mexican cazuelas de barro: glazed clay cookware,
copper-brown surfaces, burnt-orange highlights, dark fired edges, and cream
painted details. Warm ivory backgrounds and near-white raised surfaces pair with
terracotta actions and sage tertiary panels. The full neutral palette runs from
pale tan stone supporting surfaces to warm charcoal text, with subdued borders
and secondary controls. A soft tan undertone keeps the foundation earthy
while lighter surfaces reduce the brown cast. Hover and focus backgrounds use a warmer,
more saturated clay tint. DM Sans keeps body text clear, while Fraunces and
generous corners give the interface a handmade character. Dark mode uses
warm charcoal surfaces, lighter copper actions, and deep olive tertiary surfaces.
Supporting text and field boundaries remain readable on the supporting surfaces
in both schemes. Badges keep a stable background on hover because they represent
noninteractive status; buttons retain their hover feedback.
Color and typography carry the reference without decorative textures.

Choose **comal** and **light / dark** in the toolbar to preview the theme.

## Install the theme and fonts

Components work with Greda's compiled package CSS, without Tailwind:

```tsx
import "@darthcharles/greda/styles.css";
import "@darthcharles/greda/themes/comal.css";
```

Set the theme and scheme on the same boundary:

```html
<html data-theme="comal" data-color-scheme="light">
```

Importing the theme alone leaves the neutral base unchanged. Switch the scheme
to explore the complementary palette. Your application controls its page shell:

```tsx
<body className="m-0 surface-primary font-sans text-primary">
  {/* Your application */}
</body>
```

The theme references DM Sans and Fraunces but does not download fonts.
Storybook loads them through Fontsource. To reproduce that typography, optionally
install and import these packages in your application:

```bash
npm install @fontsource-variable/dm-sans @fontsource-variable/fraunces
```

```tsx
import "@fontsource-variable/dm-sans";
import "@fontsource-variable/fraunces";
```

Alternatively, self-host the fonts or override `--font-sans` and `--font-heading`.
Without loaded fonts, the theme falls back to sans-serif body text and serif
headings.

## Compose the page

The recipe uses Tailwind layout utilities. With Tailwind 4 configured, use these
imports in your application CSS entry point instead of the JavaScript CSS imports:

```css
@import "tailwindcss";
@import "@darthcharles/greda/styles.css" layer(components);
@import "@darthcharles/greda/tokens.css";
@import "@darthcharles/greda/themes/comal.css";
```

Import that entry point once. Your application Tailwind build must scan the copied
JSX; recipe-only layout classes are not included in Greda's compiled CSS. The
components layer lets application utilities override component defaults.
Tailwind 3 consumers need corresponding token mappings in their configuration.

The heading pairs a serif title with an italic action-colored phrase. A sage-toned
aside introduces the process with a clay-toned decorative mark; a raised Card
groups session details. Button, Badge,
Card, CardHeader, CardContent, and CardFooter come from `@darthcharles/greda`.
Select, Checkbox, and Label add a session choice and optional starter kit within
the session card.
The column ratio, wordmark, and decorative mark stay local to the recipe.

## Responsive layout and interaction

The two-column introduction and three-column details stack below 700px. The
header and card footer wrap when space is limited. The decorative mark is hidden
from assistive technology; session details use a semantic description list.

Tab focuses “Explore the workshop”; Enter moves focus to the workshop details
with a visible outline. Button retains anchor semantics through `asChild`; its
loading and disabled props do not guarantee a disabled link. All workshop content
is fictional. There is no registration, submission, animation, or saved state.
The session select supports arrow-key navigation and Enter to choose an option.
Space toggles the starter-kit checkbox. These preferences stay in the mounted
example and do not create a registration. See individual component stories for
disabled, loading, and validation states.

## Scoped themes

Put `data-theme="comal"` and `data-color-scheme="light"` or `"dark"` on the
same wrapper. Apply surface, text, and font styles through the shared roles.
For portaled DialogContent, SelectContent, and TooltipContent, pass an element
inside that wrapper as `container` so the portal inherits the theme. A document
theme naturally reaches portals mounted under body.

Keep the theme's low-specificity selectors. Override base colors, typography,
and shape tokens after importing the theme to customize the result. The theme
provides variables; the consuming application controls page composition.
