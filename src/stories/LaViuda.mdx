# La Viuda

La Viuda is clear, warm, and quietly contemporary. Cream carries the page,
charcoal provides readable text, and chile red marks actions and small accents.
Soft greens give supporting surfaces their own identity, with a separate green
accent for hover and focus. Geist brings the same
clean sans-serif voice to headings and body text, with tighter heading tracking,
moderate weights, thin borders, and modest corners. Spacious composition keeps
the red restrained. Dark mode uses warm charcoal surfaces and lighter red actions.

Choose **la-viuda** and **light / dark** in the toolbar to preview the theme.

## Install the theme and fonts

Components work with Greda's compiled package CSS, without Tailwind:

```tsx
import "@darthcharles/greda/styles.css";
import "@darthcharles/greda/themes/la-viuda.css";
```

Set the theme and scheme on the same boundary:

```html
<html data-theme="la-viuda" data-color-scheme="light">
```

Importing the theme alone leaves the neutral base unchanged. Switch the scheme
to explore the complementary palette. Your application controls its page shell:

```tsx
<body className="m-0 surface-primary font-sans text-primary">
  {/* Your application */}
</body>
```

The theme references Geist and does not download fonts. Storybook loads Geist
through Fontsource. To use it in your application:

```bash
npm install @fontsource-variable/geist
```

```tsx
import "@fontsource-variable/geist";
```

You can also use your application's `--font-geist-sans` variable, self-host the
font, or override `--font-sans` and `--font-heading`. Without Geist, the theme
falls back to Arial/Helvetica. Font files are not shipped in Greda's package.

## Compose the page

The recipe uses Tailwind layout utilities. With Tailwind 4 configured, use these
imports in your application CSS entry point instead of the JavaScript CSS imports:

```css
@import "tailwindcss";
@import "@darthcharles/greda/styles.css" layer(components);
@import "@darthcharles/greda/tokens.css";
@import "@darthcharles/greda/themes/la-viuda.css";
```

Import that entry point once. Your application Tailwind build must scan the copied
JSX; recipe-only layout classes are not included in Greda's compiled CSS. The
components layer lets application utilities override component defaults.
Tailwind 3 consumers need corresponding token mappings in their configuration.

This fictional ranch demonstrates a cream-led page with a wide horse
photograph, a restrained primary action, thin activity dividers, and a soft
green supporting section. Import the shown Button, Badge, Dialog, Input, Label,
and Select APIs from `@darthcharles/greda`, and copy VisitPlanner with the page.
A quiet “Plan your day” action opens the activity and group-size controls only
when needed.

## Responsive layout and interaction

The page follows a single editorial column. The photograph uses a wider crop
on desktop; activity rows stack below the medium breakpoint. Header, caption,
and footer content wrap on narrow screens. Text remains separate from the image
so it stays readable across both color schemes.

Tab focuses “Explore the ranch”; Enter moves focus to the activities with a
visible outline. Button retains anchor semantics through `asChild`; its loading
and disabled props do not guarantee a disabled link. This composition has no
booking, payment, animation, or saved state. “Plan your day” opens a dialog;
Escape or “Keep exploring” closes it and restores focus to the trigger. The
dialog and its select use a local portal container so scoped themes carry
through. Activity and guest values are temporary preview choices. See individual component stories
for disabled, loading, and validation states.

## Scoped themes

Put `data-theme="la-viuda"` and `data-color-scheme="light"` or `"dark"` on the
same wrapper. Apply surface, text, and font styles through the shared roles.
For portaled DialogContent, SelectContent, and TooltipContent, pass an element
inside that wrapper as `container` so the portal inherits the theme. A document
theme naturally reaches portals mounted under body.

Keep the theme's low-specificity selectors. Override base colors, typography,
and shape tokens after importing the theme to customize the result. The theme
provides variables; the consuming application controls page composition.
